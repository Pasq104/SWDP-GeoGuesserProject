# SWDP GeoGuesser Project

## Overview

This repository contains the development of the **SWDP GeoGuesser Project**, a multidisciplinary project combining **electronics and software** to create a system inspired by the GeoGuessr concept.

The project integrates hardware and software components to build an interactive platform capable of processing geographic data and providing a user-based guessing experience.

---

## Repository Structure

```
.
├── electronics/
│   ├── materials/      # Datasheets, component documentation, and reference material
│   └── pcb/            # PCB design files (Altium)
│
├── software/           # Source code and software components
│
├── docs/               # Documentation, reports, and project notes
│
└── README.md           # Project overview
```

---

## Electronics

The **electronics** section contains all hardware-related development.

This includes:

* PCB design files
* electronic schematics
* component datasheets
* hardware documentation

The PCB is designed using **Altium Designer**.

---

## Software

The **software** directory contains the code used to run the project system.

This may include:

* firmware
* application logic
* interfaces and communication protocols

---

## Documentation

The **docs** folder includes project documentation such as:

* design decisions
* technical notes
* development reports
* diagrams and explanations

---

## Project Goals

The goal of this project is to design and develop a system that:

* Integrates **hardware and software components**
* Demonstrates **system-level engineering design**
* Provides an interactive **GeoGuessr-style experience**
